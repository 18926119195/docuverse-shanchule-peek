# 名词表 → decide → infer 契约（2026-09-13）

> **2026-09-14 续钉**：残文补缺 `S₁` **锁定默写 + 本批回配**；完整审计稿见  
> [`book-noun-pipeline-protocol-2026-09-14.md`](./book-noun-pipeline-protocol-2026-09-14.md)。  
> 本页保留为 09-13 基线；与续钉冲突时 **以 09-14 审计稿为准**。

对齐热路径：

```
建表 S → 粗筛 LLM → S_q → 字符串定位命中点 → 拓扑袋 → decide 薄窗 → infer
```

发明权关死：LLM 只从已有表面形勾选 / 判相关；定位只认书内真出现过的串。

---

## 1. `S`（书内去重名词表）

建库时写入（提问只读）。

| 字段 | 必填 | 说明 |
|------|------|------|
| `surface` | ✓ | 归一后表面形（大小写折叠后的 canonical；展示可保留首见大小写） |
| `df` | ✓ | 全书出现次数 |
| `bookKeys` | ✓ | 出现过的 `bookKey[]`（去重、书序） |

**去重（④）——喂粗筛 LLM 前必做**

- 规则：表面完全同一词（**忽略大小写**）只留一条。  
  例：`Lacan` / `lacan` / `LACAN` → 一条。
- **不做**模糊并簇（`拉康`≈`lacan` 属别名扩展，不是本步）。
- 递送给 LLM 的可见列：**仅去重后的名词列表**（可带 `⟦n⟧` 槽号）；`df` / `bookKeys` 台侧自用。

**建表工序（可开关）**

1. 规则抽 `S₀`（扫 `atomSearchText`；拉丁专名 / 汉字 2–8；停用+频次过滤；**禁用** `tokenizeQuery`）
2. mask `S₀` → 残文 `R`（同长占位，勿硬删）
3. LLM 从 `R` 抽 `S₁`（按章分片；只补漏网专名）— **默认关**，召回不够再开
4. `S = dedupe(S₀ ∪ S₁)`

---

## 2. `S_q`（问相关名词候选）

提问时：`Q × S` → 相关子集。

| 字段 | 必填 | 说明 |
|------|------|------|
| `surface` | ✓ | 必须 ∈ `S.surface` |
| `slot` | ✓ | 粗筛窗内 `⟦n⟧`（台展开回 `surface`） |

**粗筛 LLM**

- 合法空间 = 本批 `S`；输出只许 `⟦n⟧`；**禁止造词**。
- 去重后仍长 → **分批**喂（每批只回本批槽）；台侧并成 `S_q`。
- 可先零 LLM 粗滤（问核词面 / embed **只打 S 项**，不扫正文）再进窗。

---

## 3. 命中点 `NounHit`

对每个 `s ∈ S_q`，全书字符串定位（大小写不敏感 `includes` / 正则）。

| 字段 | 必填 | 说明 |
|------|------|------|
| `surface` | ✓ | ∈ `S_q` |
| `bookKey` | ✓ | 所在门 |
| `charStart` / `charEnd` | ✓ | 相对该 chunk/`atomSearchText` 的偏移 |
| `page` | 可选 | layout 页码（有则填） |

一名词多出现 → 多条 `NounHit`。无命中的 `surface` 从后续拓扑剔除（不应发生；若发生记日志）。

---

## 4. 拓扑袋 `TopoBag`（⑦）

**定义（已钉）**：相关名词定位到出现点后，取该点前后各 **n 个与命中词不同的名词** 成集合；袋（带地址）递送 **decide**；decide 判哪些段落真正有关 → 过闸薄窗 → **infer**。

| 字段 | 必填 | 说明 |
|------|------|------|
| `anchor` | ✓ | 命中 `surface` |
| `bookKey` | ✓ | 与命中点同门（段落地址） |
| `neighbors` | ✓ | 前后各 ≤n 个**异于 anchor** 的名词表面形；袋内可再去重防刷屏；跨命中点**不去重**（各点一袋） |
| `hit` | ✓ | 回指 `NounHit`（或内嵌偏移） |

**口径**

| 项 | 取值 |
|----|------|
| 前后 n | 邻域里的**其他名词**（沿书序在名词出现流上数），不是前后 n 字符、也不是整段 T |
| 谁判相关 | **decide**（无单独「拓扑裁判」模型） |
| 谁吃正文 T | 仅 decide 过闸（`relevance≥3` / sufficient）的 `bookKey` 进 infer 薄窗 |

起步默认：`n = 5`（可配置）。decide 入窗优先送 `⟦n⟧` + 拓扑袋摘要；T 按现契约材料槽按需附带。

---

## 5. 与现热路径衔接

```
TOC（可选缩域）
  → S / S_q / NounHit / TopoBag
  → （可选）廊内短密再排：span/命中↓、T.length↑
  → decide 薄窗 ⟦n⟧(+拓扑袋)(+T)
  → prospect(relevance≥3) → infer
```

| 目标 | 手段 |
|------|------|
| 准 | TOC 缩域 + S_q 真出现 + 拓扑袋给 decide + relevance≥3 |
| 快 / 省 token | S 去重分批；拓扑袋不灌全书；少 decide 批；早停≥10 |
| 逆向调取 | `bookKey`/偏移是索引；正文按需打开（同 settle 原则） |

---

## 6. 落码顺序（决定性）

1. `bookNounIndex`：`S` 持久化 + 去重 API  
2. 定位：`S_q` → `NounHit[]`  
3. 组袋：`NounHit` → `TopoBag[]`（n 可配）  
4. 接线：`autoFlow` 在 TOC/问核之后、decide 批次之前插入队列  
5. （后开）残文 LLM `S₁`；短密细排可与 4 并行
