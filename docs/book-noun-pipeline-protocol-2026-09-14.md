# 名词管线完整协议（审计稿）· 2026-09-14

> **地位**：名词表 → 问相关粗筛 → 定位 → 拓扑袋 → decide/infer 的权威口径。  
> **相对** `docs/book-noun-pipeline-contract.md`（2026-09-13）：本页为续钉；**残文补缺 `S₁` 锁定默写 + 本批回配兜底**；未改码前以本页为准，落码后以 `src/arch/bookNounIndex.ts`（待建）为准。  
> **非目标**：不定义 query/reuse 工种全文（见写信台契约）；不把 `bbox`/门牌当抽词材料。

---

## 0. 总流程与发明权

```
A1.chunk → 纯原文 T（atomSearchText）
  → 规则抽 S₀
  → mask(S₀) → 残文 R（分批）
  → LLM 默写补缺 → 本批回配 → S₁（可多轮掩串收敛）
  → S = dedupe(S₀ ∪ S₁)          【建库持久；提问只读】
提问：
  Q × S →（可选零 LLM 粗滤）→ 粗筛 LLM（⟦n⟧ 上色）→ S_q
  → 字符串定位 → NounHit[]
  → 组袋 → TopoBag[]
  → decide 薄窗 → prospect(relevance≥3) → infer
```

| 原则 | 口径 |
|------|------|
| 发明权 | 补缺默写：**只许抄本批 R 内连续子串**；粗筛：**只许勾本批 S 的 `⟦n⟧`**；禁止造词 |
| 材料脸 | 抽词/默写/定位的正文 = `atomSearchText(chunk)`；**禁止**把 `key` / `bbox` / `page` / `slotK` / `vBook` / 导出 `KEY:` 行当 T |
| 地址脸 | `bookKey`、偏移、页码只做台侧索引与开门；**不进**补缺/粗筛的「词」空间 |
| 坐标 | 造名词表与补缺 LLM：**不使用**旧坐标定义 |

## 1. 材料面：`T`（不是名词表）

| 项 | 规定 |
|----|------|
| 来源 | A1 `BookIndex.chunks` |
| 取值 | `atomSearchText(c)`；`isRetrievableAtom` 过滤空/fig 壳 |
| 洗净（抽 S₀ / 制 R 前） | 去 HTML 标签、Markdown 壳噪声（实现可开关）；不停用正文专名 |
| 禁止进入抽词池 | 整 chunk JSON、门牌、bbox、机读 fig 模板句、不可检索占位 |

## 2. `S₀`：规则名词粗表

**时机**：建库（提问只读 `S`）。

**工序**

1. 扫全部合法 `T`（禁用 `tokenizeQuery` 作抽词器）。  
2. 候选形态（可配置，默认）：  
   - 拉丁：专名形态（含连续大写/首大写词、可含连字符）；  
   - 汉字：连续 2–8 字。  
3. 停用表 + 极端频次过滤（过高功能串 / 过低碎屑可闸）。  
4. 忽略大小写整串归并；展示形保留首见大小写。  
5. 抽词阶段只产出 Draft；**不含** `bookKeys` / 坐标。频次不预存（回 A1 再算）。

| 字段 | 必填 | 说明 |
|------|------|------|
| `text` | ✓ | 书中连续原文串（规则抠出） |

- 抽词/默写阶段只有 `BookNounDraft = { text }`，**不含** `bookKeys`。  
- `S₀ ∪ S₁` 在 Draft 上整串去重后即得权威表 **`S`（仍是 Draft）**。  
- **建表不做 locate**；门牌留到提问：`S_q` → 在 A1/`T` 上定位 → `NounHit`。

**风险与兜底**：规则漏 → 交 `S₁` 默写补；规则脏 → 停用/频次 + 后续定位无命中则难进拓扑（见 §6）。

## 3. 残文 `R` 与补缺 `S₁`（**锁定默写**）

### 3.1 制残文

1. 在各 chunk 的 `T` 上，将已入 `S₀` 的 `text`（大小写不敏感）替换为 **同长占位**（勿硬删，免偏移错乱）。  
2. 得残文流 `R`；分批主路径见 §3.4：**S₀ 相邻落点间隙并行**；过长间隙内串联。拼接 R 时 **禁止** 对 unit 做 trim/filter（否则 S₀ 偏移错位）。

### 3.2 默写 LLM：输入 / 输出

**输入（仅含）**

- 任务说明：从残文抄漏网专名/名词；只许原文连续片段；禁止改写、禁止别名翻译。  
- 本批残文正文 `R_batch`。  
- **不得**含：`bookKey`、bbox、坐标、S₀ 列表当「可抄词表」（S₀ 已 mask；避免模型只回显表）。

**输出（JSON，示意）**

```json
{"nouns":["Guattari","schizoanalyse","cartographies schizoanalytiques"]}
```

- 每项为字符串；允许短语（连续多词）。  
- 可包在 \`\`\`json 中；台侧解析失败 → **整批重试一次**；仍失败 → 本批 `S₁` 记空，转 §3.4 规则二轮。

### 3.3 收卷硬闸（乱编 / 错选归零）

对每个输出串 `w`：

| 检查 | 失败则 |
|------|--------|
| 非空、去首尾空白 | 丢弃 |
| **必须是本批 `R_batch` 的连续子串**（建议大小写敏感优先；收卷键再 ignore-case 归并） | 丢弃并记账 `reject:not_substring` |
| **回配作用域 = 本召输入字符串**（禁止全书 / 其它批 `includes`） | 违纪视为实现错误 |
| 停用 / 纯数字 / 纯标点 / HTML 碎片 / 过短 | 丢弃 `reject:noise` |

通过者进入本批 `S₁_batch`。

**去重（批内 / `S₀∪S₁`）——只许整段连续表面形全等**

- 归一：ignore-case + 空白折叠后，**整串相同**才并成一条。  
  例：`Lacan` / `lacan` → 一条。  
- **禁止**子串/超串吞并：`Lacan` 与 `Jacques Lacan` **必须分列**（二者都是书中合法连续串时不得互删）。  
- **禁止**最长串合并、模糊并簇、别名折叠。

### 3.4 漏选兜底（掩串多轮，可收敛）

目标：长残文下漏选可收敛，不依赖「未涂槽名单」。

```
已收串（本批 S₁_batch ∪ 本批已覆盖）
  → 在 R_batch 上掩同串 → R′
  → 对 R′ 高召回规则扫候选 C′
  → 二轮：默写只读 R′，或只让默写/规则处理 C′
  → 新通过子串并入 S₁_batch
  → 无新增或达轮次上限 → 停
```

| 参数 | 默认建议 |
|------|----------|
| 最大补缺轮次（每批） | 2（首轮默写 + 至多一轮掩后） |
| 分批 | **主路径**：S₀ 相邻落点间隙 **可并行**默写；**跨 S₀ 切口**与间隙内串联同一套：截断处往前 `priorNouns`（默认 2）个名词样串作前缀重叠（含中间 █），避免规则短词把短语拆到两批互不见面 |

可选：对「已通过子串闸」的候选再跑 **是/否二判 LLM**（闭集：只评给定列表，不造词）→ 降错选。

### 3.5 合成

```
S₀ Draft ∪ S₁ Draft
  → dedupeNounDrafts（仅整串全等）
  → S（建表结束；仍是 `{ text }`，无 bookKeys）
```

- 抽词/默写/建表类型均为 `BookNounDraft = { text }`。  
- **禁止**在建表末尾 `attachBookKeysByLocate`；locate 只在提问链路（§6）。

### 3.6 明确不采用（补缺路径）

- 残文补缺 **不采用** 按字开槽上色（token 贵；本协议用默写 + §3.3–3.4 兜底）。  
- 补缺 **不使用** 坐标/门牌。

### 3.7 开关

- `S₁` 默写整段可配置开关；默认建议：**开**（与 09-13「默认关」相比，以本审计稿为准若产品选择开启）。  
- 关闭时：`S = S₀`。

## 4. `S`：权威书内去重名词表（建库 Draft）

| 字段 | 必填 | 说明 |
|------|------|------|
| `text` | ✓ | 连续原文串（S₁=LLM 回配切片；S₀=规则抠出） |

> 建库只存词面。定位针仍是同一条 `text`，但 **locate 发生在提问**（§6），不预挂 `bookKeys`。

- 建库写入；提问只读。  
- **不做** `拉康`≈`lacan` 模糊并簇（别名属问核，不是本表）。  
- 喂粗筛 LLM 的可见列：**仅去重后的名词列表 + `⟦n⟧`**。

---

## 5. `S_q`：问相关名词（粗筛 = **上色**，非默写）

**时机**：提问。`Q × S` → 相关子集。

| 字段 | 必填 | 说明 |
|------|------|------|
| `text` / 槽对应 | ✓ | 必须 ∈ `S.text`（粗筛可见列用槽号，不另存 surface） |
| `slot` | ✓ | 本批窗内 `⟦n⟧` |

**粗筛 LLM**

- 合法空间 = 本批 `S` 槽；**输出只许 `⟦n⟧`**；禁止造词、禁止默写新串。  
- `S` 过长 → 分批；每批只回本批槽；台侧并成 `S_q`。  
- 可先零 LLM 粗滤（问核词面 / embed **只打 S 项**，不扫正文）再进窗。  
- 非法槽号 → 丢弃记账。

**与补缺分工**

| 阶段 | 答卷形态 |
|------|----------|
| 建库补 `S₁` | **默写** + 本批子串回配 |
| 提问粗筛 `S_q` | **`⟦n⟧` 上色**（闭集=S） |

---

## 6. `NounHit`：命中点（**提问时 locate**）

对每个 `s ∈ S_q`，用其 `text` 在全书合法 `T` / A1 上定位（大小写不敏感）。  
可用 `attachBookKeysByLocate`（或等价实现）——**仅此阶段**，不进建表。

| 字段 | 必填 | 说明 |
|------|------|------|
| `surface` | ✓ | ∈ `S_q` |
| `bookKey` | ✓ | 所在门 |
| `charStart` / `charEnd` | ✓ | 相对该 chunk `T` 的偏移 |
| `page` | 可选 | layout 页 |

- 一词多出现 → 多条 hit。  
- **无命中** → 从后续拓扑剔除，打日志（数据异常或 S 脏）。

---

## 7. `TopoBag`：拓扑袋

**定义**：命中点上，沿书序名词出现流，取前后各 **n** 个 **异于 anchor** 的名词表面形成袋；带地址交 decide。

| 字段 | 必填 | 说明 |
|------|------|------|
| `anchor` | ✓ | 命中 surface |
| `bookKey` | ✓ | 与 hit 同门 |
| `neighbors` | ✓ | 前后各 ≤n 个异名词；袋内可去重；跨 hit **不去重** |
| `hit` | ✓ | 回指 NounHit |

| 项 | 取值 |
|----|------|
| n | 默认 5，可配 |
| 邻域单位 | 名词出现流上的其他名词，**不是**前后 n 字符、不是整段 T |
| 谁判段相关 | **decide**（无单独拓扑裁判模型） |
| 谁吃正文 T | 仅 decide 过闸（`relevance≥3` / sufficient）的门进 infer |

decide 入窗：优先 `⟦n⟧` + 拓扑袋摘要；T 按材料槽按需附带。

## 8. 与热路径衔接

```
TOC（可选缩域）
  → S / S_q / NounHit / TopoBag
  →（可选）廊内短密再排
  → decide 薄窗
  → prospect(relevance≥3) → infer
```

| 目标 | 手段 |
|------|------|
| 准 | TOC 缩域 + S_q∈S + 真命中 + 拓扑袋 + relevance≥3 |
| 省 | S 去重分批；袋不灌全书；decide 早停 |
| 逆向 | bookKey/偏移索引；正文按需打开 |

**下游相关（不在本页展开全文，审计时交叉）**

- decide 解问相关度 / 禁专名撞词硬铸：`letterDeskContracts` / prospect relevance  
- query `reuseEligible` 硬闸：写信台进度备忘 / `queryReuseAuth`  
- A1 导出全局一份全文：抽词用内存 T 或 jsonl 的 `T` 字段，勿扫 md 的 `KEY:` 行

## 9. 风险总表与兜底（审计用）

### 9.1 补缺默写 `S₁`

| 风险 | 兜底 |
|------|------|
| 乱编 / 抄错 / 近义改写 | 本批 `R_batch` 连续子串硬闸 |
| 跨批误配 | 回配作用域=本召输入；禁全书匹配 |
| 长残文漏选 | 掩串 → R′ → 规则/二轮默写；轮次上限 |
| 功能词等错选 | 停用形态剔；可选闭集二判 |
| 短语长短不一 | **勿用最长串吞并**；整串全等才去重；`Lacan`≠`Jacques Lacan` |
| JSON 失败 | 校验；整批重试一次；再失败转规则二轮 |
| 非原文材料 | 只喂 atomSearchText；禁坐标门牌 |

### 9.2 粗筛上色 `S_q`

| 风险 | 兜底 |
|------|------|
| 造词 | 只收 `⟦n⟧` |
| 错选 | 非法号丢弃；可选对勾选槽二判 |
| 漏选 | 未勾槽可二轮只问未涂；或扩批/降零 LLM 粗滤阈值 |
| 批次切表 | 并集；槽号不跨批复用同一语义号（每批独立编号） |

### 9.3 定位 / 拓扑

| 风险 | 兜底 |
|------|------|
| S 中词书中无命中 | 剔出拓扑；日志 |
| 袋噪声 | n 可配；袋内去重；decide relevance 闸 |

## 10. 落码顺序（决定性）

1. `bookNounIndex`：`T` 抽取、`S₀`、`S` 持久化、dedupe API  
2. `S₁` 默写管线：分批、本批回配、掩串多轮、开关  
3. `S_q` 粗筛：`⟦n⟧` 分批上色  
4. `S_q` → `NounHit[]`  
5. `NounHit` → `TopoBag[]`（n 可配）  
6. `autoFlow`：TOC/问核之后、decide 之前接入
